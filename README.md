# 🎮 MATH MANIA - Calculation Challenge

### Challenge Your Mind, One Calculation at a Time!

Math Mania is a simple and interactive mathematical game developed using HTML, CSS, and JavaScript. It helps users improve their calculation speed and accuracy through fun mathematical challenges.

## 🚀 Features

- Three difficulty levels: Easy, Medium, and Hard.
- Random mathematical questions.
- 10-second countdown timer for each question.
- Automatic generation of the next question after a correct answer.
- Score tracking.
- Game ends when the user gives an incorrect answer or time runs out.
- Final score display.
- Play Again option.
- Back to Home option.

## 🛠️ Technologies Used

- HTML5 - Structure of the website.
- CSS3 - Styling and page design.
- JavaScript - Game logic and functionality.
- Local Storage - Storing difficulty level and score.

## 🎯 How to Play

1. Open the Math Mania home page.
2. Select your preferred difficulty level.
3. Click on START CHALLENGE.
4. Solve the displayed mathematical question within 10 seconds.
5. Enter your answer and click Submit Answer.
6. Get one point for every correct answer.
7. The game ends if you submit an incorrect answer or the timer reaches zero.
8. View your final score.
9. Click Play Again to restart or Back to Home to return to the main page.

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Double-click on index.html.
4. The game will open in your web browser.

No additional software or server is required.
